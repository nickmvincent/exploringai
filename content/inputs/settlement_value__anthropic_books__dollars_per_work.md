# Proposed settlement value per work (Anthropic books case)

**Value:** 3,000 dollars per work

## Description

Approximate proposed gross allocation per identified work at preliminary approval.

## Key Assumption

This is a proposed gross settlement benchmark from the preliminary-approval opinion, not a final payout or court-declared market value. Fees, costs, multiple rightsholders, and final approval can affect recoveries.
