# Anna's Archive data Meta allegedly torrented

**Value:** 81.7 terabytes

## Description

Plaintiffs' lower-bound estimate for one alleged Anna's Archive acquisition.

## Key Assumption

This is an allegation in a party filing, not a judicial finding or Meta admission. It is not Meta's total shadow-library data, a deduplicated corpus size, or proof that every byte entered training.
